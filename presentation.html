01 — PROJECT BACKGROUND

为什么做这个项目？

应届生求职时面临的核心矛盾，以及 AI 如何介入

⚠

用户痛点

应届生看到 JD 上的「有经验」「熟悉XX」就发懵 —— 知道要准备项目， 但不知道做什么、怎么做、做到什么程度算够。投了 50 份简历石沉大海， 却不知道问题出在哪里。

→

产品解法

用 AI Agent 自动分析 JD，搜索真实开源项目和数据集， 生成可执行的项目路线图。再用简历 X 光机逐项扫描匹配度， 形成「分析 → 执行 → 验证」的完整闭环。

CORE INSIGHT
JD 不是门槛，是路线图。每一句「任职要求」都对应一个可执行的项目 —— 缺的不是能力，是把能力翻译成行动的方法。

04 — TECH HIGHLIGHTS

技术亮点（一）

区分"调了一次 API"和"做了个 AI Agent"的关键

// HIGHLIGHT_01

Agent Loop + Function Calling

Transit 不是单次 API 调用，而是真正的 Agent 循环。 AI 自主决定调用什么工具、搜索什么关键词、 什么时候停止搜索开始总结。最多 8 轮，每轮都有明确的 tool_call 和 tool_result。

// Agent Loop for (let i = 0; i < 8; i++) { const res = await callDeepSeek(messages, tools); if (res.tool_calls) { // AI 自主决定调用工具 const result = await executeTool(res.tool_calls); messages.push(result); } else { // AI 决定停止搜索，输出结果 return res.content; } }
// HIGHLIGHT_02

SSE 流式推送

用户不用等 Agent 跑完才看到结果。每一步思考、工具调用、 返回结果都通过 Server-Sent Events 实时推送到前端， 体感上"AI 正在思考"。

// Edge Function SSE const stream = new ReadableStream({ start(controller) { controller.enqueue( `data: ${JSON.stringify({ type: 'thinking', content: '正在分析JD...' })}\n\n` ); } }); return new Response(stream, { headers: { 'Content-Type': 'text/event-stream' } });
04 — TECH HIGHLIGHTS

技术亮点（二）

浏览器端解析 + 两阶段 JSON 格式化 + 混合部署

// HIGHLIGHT_03

浏览器端文件解析

Screen 的 PDF/DOCX 解析完全在浏览器端完成。 pdfjs-dist 用 Web Worker 解析 PDF 文字层， mammoth.js 提取 DOCX 纯文本。 文件不上传服务器，保护用户隐私。

// 浏览器端 PDF 解析 pdfjsLib.GlobalWorkerOptions.workerSrc = 'https://cdn.jsdelivr.net/npm/pdfjs-dist@3.11.174/build/pdf.worker.min.js'; const pdf = await pdfjsLib.getDocument({ data: arrayBuffer }).promise; for (let i = 1; i <= pdf.numPages; i++) { const page = await pdf.getPage(i); const text = await page.getTextContent(); fullText += text.items.map(t => t.str).join(' '); }
// HIGHLIGHT_04

两阶段 JSON 格式化

先让 Agent 自由思考生成自然语言总结（高 temperature）， 再用低 temperature（0.3）格式化为严格 JSON。 兼顾创造性和结构化，解析失败时自动发起修复请求。

// Phase 1: 自由思考 const summary = await callDeepSeek({ temperature: 0.8, prompt: '根据JD推荐3个项目...' }); // Phase 2: 严格格式化 const json = await callDeepSeek({ temperature: 0.3, prompt: '将以下内容转为严格JSON...', input: summary });
